# CMF Buds Pro 2 Manager

[English](../README.md) · [Скачать APK](https://github.com/copilotfather/cmf-buds-pro-2-manager/releases/latest) · [Бета часов](WATCH_BETA.md)

Независимое Android-приложение для **CMF Buds Pro 2** с экспериментальной поддержкой **CMF Watch Pro 2**. Проект не связан с Nothing или CMF.

## Возможности

- Пятиполосный эквалайзер: пресеты, ручные кривые, JSON, сравнение A/B, инверсия и общий сдвиг ±1 dB.
- Профили «Метро», «Работа», «Игры», «Сон» с сохранением своих настроек.
- Диагностика аудио, SPP и BLE; чтение ANC после команды.
- Семь виджетов: пульт, заряд, ANC, прозрачность, игровой режим, бас и подключение. Светлый/тёмный стиль, акценты, выбор третьей кнопки пульта.
- История заряда за семь дней и предупреждение о разнице между наушниками.
- Поиск слева/справа с подтверждением безопасности, последняя известная позиция телефона при отключении.
- Таймер сна, фоновые звуки, голосовые подсказки и обновления с GitHub.

## Установка

1. Скачайте `CMF_Buds_Pro_2_Manager.apk` из последнего релиза.
2. Установите APK на Android 8.0 или новее.
3. Сопрягите наушники через настройки Android и предоставьте приложению Bluetooth-разрешения.
4. Для виджетов удерживайте рабочий стол → «Виджеты» → CMF.

## Watch Pro 2 — бета

Настройки → **DEV** → пароль **`betatestdev`** → включить бету → поиск → подключение → авторизация. Подтвердите сопряжение на часах. Закройте другое приложение часов; сопряжение может заменить его привязку.

Реализованы BLE, зашифрованная сессия, синхронизация шагов, расстояния, калорий, пульса, SpO₂, стресса и сна. Уведомления включаются отдельно, только для выбранных приложений и при разблокированном телефоне. После переподключения авторизация повторяется. Разбор тренировок и Health Connect пока отсутствуют.

## Что проверено

Release-сборка и четыре unit-теста протокола часов проходят. **На физических устройствах текущие функции ещё не проверены.** Применение команд зависит от прошивки. Для баса и игрового режима успешная отправка не означает подтверждение применения.

Android выбирает фактический кодек и битрейт LDAC. Эквалайзер зависит от поддержки аудиоэффектов телефоном и плеером. Прогнозы батареи и слуховой нагрузки являются оценками. На карте показывается позиция телефона, а не текущая позиция потерянных наушников.
